# Advtage releases

Public **Windows installers and auto-update files** for [Advtage](https://advtage.github.io/) — a local TTRPG table app (Tauri).

## What this repo is
- **Installers / updater assets only** (NSIS `.exe`, `.sig`, `latest.json`, etc.)
- Source code is **private** and is not published here
- Installed Advtage apps check **this repo's GitHub Releases** for updates via `latest.json`

## Download
1. Open [Releases](https://github.com/dylan-griffin/advtage-releases/releases/latest)
2. Grab the Windows NSIS `.exe` (prefer that for testers)
3. Install per-user and let the in-app updater handle later versions

If you found this by accident: you can download a release asset, but please only use builds Dylan shared with you.
